# nick-amble-channel

Nick's channel on [amble.channel](https://amble.channel/nick/) — CH 001.

This repo is the **user-generated content**; the platform lives at
[amblechannel/amble-channel](https://github.com/amblechannel/amble-channel).
The split is the point: amble.channel provides pages, the people on it own
their content. This is nick's.

- `nick/index.html` — the channel page. GENERATED by the amble engine
  (`channel/page.py`) from page data on nick's machine; co-created with his
  amble by voice, published by his click. Don't hand-edit.
- `nick/easter-bunny/` — "The Easter Bunny, 2077," the first storytime
  broadcast. Hand-authored.

**Serving wire-up pending:** amble.channel currently serves this content
from a copy inside the platform repo. Until the reference lands (submodule
or Actions assembly), the platform copy is what's live and this repo is the
declared source of truth.
